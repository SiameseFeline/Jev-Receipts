# Jev Receipts

**223 real-world Jev use cases, graded on evidence.**

![Jev Receipts](https://jev-receipts.pages.dev/social.png)

Jev Receipts shows what [Jev](https://typesafe.ai) does in real workflows — not just what it can benchmark. Every entry is graded on evidence strength, and weak evidence is never made to sound strong.

🌐 **Live site:** https://jev-receipts.pages.dev

## The standard

- **Lead with practical utility** — what job does this help someone do?
- **Grade every entry by evidence strength** — independent test with metrics ranks highest, then builder demos, then proposals, then vendor claims. A high utility rank never upgrades weak evidence.
- **Never make weak evidence sound strong.**

## What's inside

| File | What it is |
|---|---|
| `index.html` | The entire site — one self-contained static file, no build step, no backend. |
| `social.png` | Social share card (1200×630). |
| `use-case-catalogue.md` | The open dataset: all 223 use cases with evidence tiers, metrics, and sources. |

The site is a single HTML file on purpose: anyone can open it, audit it, or fork it in seconds.

## Contribute a use case

Built something with Jev? Post it publicly and tag [@stepintoBEra](https://x.com/stepintoBEra) on X so the evidence can be reviewed for the next update. Strong, independently-measured evidence jumps the queue.
